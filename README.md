# 屏幕亮度调节助手

一个使用 C++ / Win32 编写的 Windows 屏幕亮度调节小工具。

软件主要用于快速切换常用显示模式，并保存最后一次设置。适合笔记本和台式机使用，台式机外接显示器会优先尝试通过 DDC/CI 调节亮度，不支持时使用 Gamma 和护眼滤镜作为辅助方案。

## 功能

- 标准、护眼、防蓝光、游戏四种显示模式
- 亮度滑动调节
- 自动保存最后一次模式和亮度
- 支持笔记本内置屏幕亮度调节
- 支持外接显示器 DDC/CI 亮度调节
- 护眼、防蓝光模式带暖色滤镜
- 登录后可静默恢复上次设置
- 绿色简洁界面

## 使用方法

1. 运行程序。
2. 选择需要的显示模式。
3. 拖动亮度滑动条调整亮度。
4. 关闭窗口即可。

护眼和防蓝光模式为了保持滤镜效果，关闭窗口后会隐藏主界面并保留后台滤镜。切换回标准或游戏模式后，滤镜会关闭。

## 编译

需要安装 Visual Studio C++ 生成工具。

在 PowerShell 中进入项目目录后执行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

编译后的程序会生成在：

```text
dist\屏幕亮度调节助手 - Thebzk@52pojie.exe
```

## 说明

- 部分台式显示器需要在显示器菜单中开启 DDC/CI 才能调节硬件亮度。
- 如果显卡或显示器不支持 Gamma 写入，护眼和防蓝光效果会依赖滤镜窗口。
- 程序使用管理员权限运行，用于创建登录恢复任务和访问部分显示设置。
